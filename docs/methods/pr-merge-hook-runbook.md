# Managed PR merge hook runbook — retired

This runbook is retired. Its former product-hook probes and audit procedures describe hooks removed by Issue #542 and must not be used as current operating instructions. The historical text is preserved in [`docs/archive/pr-merge-hook-runbook-2026-10-02.md`](../archive/pr-merge-hook-runbook-2026-10-02.md).

The current boundary denies merge and auto-merge operations to AI roles and the main context. The owner reviews the fresh blocker report and performs any merge manually. See [`docs/tools/pr-merge-gate.md`](../tools/pr-merge-gate.md) for the current permission rules, report command, and their limits.
