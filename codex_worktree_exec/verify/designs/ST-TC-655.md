    - G2（uv と Python の版の設定が既定）：次の path がどれも存在しない（存在を確かめられない path は、存在するものとみなす）。
      - (a) 祖先の設定：Q と Q の各祖先ディレクトリと、ケースの worktree の root の各祖先ディレクトリの、直下の `uv.toml`・`pyproject.toml`・`.python-version`・`.python-versions`・`.venv`。09-3 では、ケースの worktree の root 自身の直下の同じ path も含める（09-3 の行は本 VD が固定した行で、root の設定は、M の内容であっても（base 側の別 PR が加えたものを含む）、AC9 が判定する分類と無関係に行の interpreter や取得を変えるため）。13-2・13-3 では root 自身を含めない（root の設定は M の内容であり、手順の行を M で実行した結果として判定に含める）。祖先にあるときは、判定者がケースの worktree か Q を別の場所に作り直してよい（09-3 の root 自身にあるときは作り直しても変わらないので (u1)）。
      - (b) uv の利用者と system の設定の候補：`XDG_CONFIG_HOME` が空でなければ `$XDG_CONFIG_HOME/uv/uv.toml` と `$XDG_CONFIG_HOME/uv/.python-version`。`$HOME/.config/uv/uv.toml` と `$HOME/.config/uv/.python-version`。`XDG_CONFIG_DIRS` が空でなければ `:` で区切った各要素 d の `d/uv/uv.toml`。`/etc/xdg/uv/uv.toml`。`/etc/uv/uv.toml`。候補の出典は、uv の文書の設定ファイルの節（https://docs.astral.sh/uv/concepts/configuration-files/ 。利用者の設定 `~/.config/uv/uv.toml`（または `$XDG_CONFIG_HOME/uv/uv.toml`）と system の設定 `/etc/uv/uv.toml`（または `$XDG_CONFIG_DIRS/uv/uv.toml`））と、XDG Base Directory 仕様（https://specifications.freedesktop.org/basedir-spec/latest/ 。`XDG_CONFIG_DIRS` が未設定または空のときの既定値は `/etc/xdg`）である。本 VD は uv がこれらをどの順に探し、最初の1つだけを読むか重ねて読むかを前提にしない。候補をすべて確かめ、1つでも存在すれば G2 を満たさないとするので、探索順によらず同じ結果になる（候補は ac-designer が文書から列挙したもので、ac-designer は実測していない）。

    - G4（13-2・13-3。coverage の取得）：次の4つがすべて終了コード0で終わる。`uv run --with coverage python -c "import coverage"`、`uv run --no-cache --with coverage python -c "import coverage"`、`uv run --python <X> --with coverage python -c "import coverage"`、`uv run --python <X> --no-cache --with coverage python -c "import coverage"`。uv の既定の選び方で選ばれる interpreter と E の `python3` の interpreter のそれぞれで、uv の cache を使う場合と使わない場合に、配布元から coverage を取得できることを確かめる。G4 を満たさない場面は、`.ai/skills/coverage-html/SKILL.md` の、uv が使えなければ停止してオーナーに打ち上げる定めと同じ場面である。
