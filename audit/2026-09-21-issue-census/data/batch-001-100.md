## 注記（表の読み方）
- `author_kind` は本文中の attribution 文言（「🤖 起票: Claude Code（AIエージェント）」「🤖 Generated with Claude Code」「🤖 **Claude Code（AI）による対応**」等）の有無で判定した。末尾の `https://claude.ai/code/session_...` リンクのみで明示の attribution 文言が無いもの（#5〜#11 等）は `owner` とした（推測で `ai-claude` にしていない）。
- `resolution` は GitHub API の `state_reason` を一次根拠にした。`completed` → `implemented`、`not_planned` かつ本文に統合先が明記（#4 → #141）→ `merged-into`、`state=open` → `open`。
- `mechanized` は本文の受け入れ条件・対応内容に「TDD」「全テスト green」「単体テスト追加」「lint/hook/gate 新設」「fail-close 追加」等の明記があるものを `yes`、テスト言及はあるが必須要件でない・一部のみのものを `partial`、文書/設定/方針変更のみで機械検査の追加が本文に書かれていないものを `no`、本文だけでは判別不能なものを `unknown` とした。
